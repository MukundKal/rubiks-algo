# Rubiks Algo (Wear OS)

## I built this because remembering 8 simple algorithms is apparently too hard for a human adult.

### It’s a cheat sheet for your wrist. It uses the physical bezel to scroll because swiping is for peasants, and it’s pitch black to save your battery for more important things, like checking the time.

## Features:

**Minimalist UI:** Text on a black background. Groundbreaking design.

**Bezel Support:** Spins like the cube you can't solve.

**OLED Friendly:** Because I care about your 14-hour watch battery life.

Built with Jetpack Compose because I like over-engineering simple problems.
